# AI Assistance in Documentation

This file documents where and how AI tools (primarily ChatGPT by OpenAI) were used to support the creation and refinement of documentation for the Rent Tracker project.

## Purpose

AI assistance was used to:
- Rephrase and polish explanations for clarity and professionalism
- Suggest content structure for documentation pages
- Draft descriptions of UI, architecture, and data models in natural language
- Help with naming, formatting, and consistency in documentation

⚠️ Note: Help related to writing, improving, or debugging code is documented separately in [`code_snippets`](code_snippets.md).

## Affected Files

| File | Type of Assistance |
|------|---------------------|
| `docs/technical_docs/architecture.md` | Rephrased complex architectural descriptions |
| `README.md` | Helped structure project introduction, setup guide, and phrasing |
| `docs/design_decisions.md` | Assisted with content flow and wording of key decisions + formatting|
| `docs/data_model.md` | Helped drafting first version of the data model and then transcribed the final one with consistent and readable entity descriptions |
| `docs/contributions.md` | Improved clarity of what we wanted to say |
| `docs/goals_achieved_missed.md` | Helped with structuring and creating the file formatting |
| `docs/goals.md` | Ideation process and then helping to formulate the goals properly using the SMART method |
| `docs/improvements.md` | Paraphrased and formulated in organized way chain of thoughts |
| `docs/technical_docs/reference.md` | Recheck if all routes were included in the documentation and paraphrasing |
| `docs/value_proposition.md` | Helped formulation unstructured thoughts in organized flow of information |
| `docs/wiki/git_workflow.md` | Created a workable workflow instructions for team members on Git usage |

> All AI-generated suggestions were critically reviewed, edited, and approved by the project team.
